The Program will go as so:
Player/Learner will be greeted with a start menu in VR
Clicks start, then pc parts are scattered around the room
Parts such as: 
>Pc Case
>Motherboard 
>Graphics processing Unit (GPU)
>Central Processing Unit (CPU)
>CPU cooler
>Solid state drives (SSD memory)
>randomly allocated memory (RAM)
>Power Supply Unit

The Learner will see the highlighted part that needs to be put in first
Once they grab it, it will show a text prompt attached to the part - explaining what it does, how it functions, what to be careful of and Where it goes through image based PNGS!
The player will follow the PNG guides to slot the parts in one by one using AMD PC PARTS until a computer is fully built
Then once its powered on -> WIN! congratulations you are now viable to build COMPUTERSSSS!

The main goal is to teach people how to safely build a computer by hand with limited guides
Certain warnings will show up stating the dangers of static electricity and how to be gentle with parts.
